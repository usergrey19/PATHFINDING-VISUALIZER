The primary goal of this project is to design and implement a real-time, interactive Pathfinding and Heuristic Search Visualizer in the C programming language to visually demonstrate and benchmark core graph traversal algorithms. Our completed desktop application renders an interactive 25×43 2D grid inside a native Windows GUI. Users can dynamically drag Start and Target nodes, draw impenetrable walls or high-cost weighted terrain (Mud tiles costing 5× movement energy), and procedurally generate complex labyrinths using Recursive Backtracking.
The visualizer implements four fundamental algorithms from scratch: Breadth-First Search (BFS), Depth-First Search (DFS), Dijkstra’s Algorithm, and A* (A-Star) Search (using the Manhattan distance heuristic). Furthermore, the final phase introduces a 4-Way Simultaneous Split-Screen Comparison Mode, enabling all four algorithms to execute concurrently on identical maps while displaying live telemetry on visited nodes, shortest path cost, and sub-millisecond CPU compute time
The final system is engineered in standard C using a modular four-file architecture (visualizer.h, datastructures.c, algorithms.c, and main.c) and the native Windows Graphics Device Interface (<windows.h> and GDI32):
Encapsulated Multi-Instance Graph Model (visualizer.h): The grid is modeled as a 25×43 2D array of Node structures (1,075 vertices) supporting 4-directional cardinal connectivity. To enable simultaneous 4-way comparison without state collisions, we designed an encapsulated SearchInstance structure that bundles each algorithm's independent grid state, frontier data structure, and telemetry counters.
Custom Abstract Data Types (datastructures.c): All data structures are implemented from scratch without external libraries:
	Binary Min-Heap (Priority Queue): Provides O(log⁡V ) insertion (heapify-up) and extraction (heapify-down) for Dijkstra and A*.
	Circular FIFO Queue: Provides O(1) wrap-around operations for BFS.
	LIFO Stack: Provides O(1) push and pop operations for DFS.
